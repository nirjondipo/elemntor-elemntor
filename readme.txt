A custom Elementor plugin for building advanced Elementor widgets and extensions.

== Description ==

Elemntor Elemntor is a custom WordPress plugin that extends Elementor with custom widgets and functionality. Build powerful, custom Elementor widgets with this plugin as your foundation.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/elemntor-elemntor` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Make sure Elementor is installed and activated
4. Start building custom widgets!
